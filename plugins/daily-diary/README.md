# 会话日记插件

一个独立安装的 CipherTalk 静态插件。1.4.0 使用宿主新增的“历史有效聊天日期”查询，
并依赖支持 1M 字符 `ai.complete` 上限的 CipherTalk 版本。

## 功能

- 搜索并选择一个微信会话
- 选择开始日期和结束日期
- 在主页选择日期范围并手动生成
- 日期范围按天串行处理，每一天单独使用 `query` 的 `limit + cursor` 分页读取
- 每天独立完成消息读取、语音转写、历史上下文构建、AI 生成和保存后，再处理下一天
- 每个日期独立调用一次 AI，不合并不同日期的请求
- 逐日 AI 调用自动控制间隔，避免超过宿主每分钟 20 次的调用预算
- 每天的语音独立转写，不与其他日期的语音混合；当天内部按宿主允许的两路并发执行
- 不提前截断单条文字或语音转写，也不再限制每天的语音条数
- 目标日期 D 使用当天完整文字与语音转写；向前参考最近 7 个真正有文字或语音的聊天日期
- R1 始终使用最近有效日期的原始聊天；R2～R7 优先使用同会话已有日记，缺失时逐日回读原始聊天
- 每个日期的数据分别用 `query(limit=2000, cursor)` 读取和转写；不批量拉取或混合多日正文
- 不设每天 2,000 条消息的提前上限，持续翻页到日期结束，并保留 100 页异常保护
- 单次生成任务内按“会话 + 日期”缓存读取及转写结果，日期范围生成可复用但不会持久化缓存
- `system + prompt` 最多 1M 字符，并预留 4,096 字符结构空间
- 超限时依次缩减旧日记、较旧原始参考日、R1，最后才首尾截取目标日期 D
- 日记保存引用日期、上下文字符数、每个日期的原始/日记来源和裁剪区块等审计信息
- 同一天重新生成时覆盖旧日记
- 调用 CipherTalk 已配置的语音转写能力，将语音转换为文字
- 使用 CipherTalk 已配置的大模型生成 Markdown 日记
- 自定义并保存日记提示词
- 内置适合亲密关系私聊的细腻、克制型默认提示词
- 首页以卡片形式展示最近 60 篇日记
- 首页卡片展示日记标题，日期后同时显示星期
- 右上角“日记设置”弹窗只保存会话和提示词
- 在“日记设置”中将全部日记导出为 JSON 备份
- 从 JSON 备份恢复日记，导入前确认同日覆盖数量
- 右上角“重新生成”直接重新生成最近阅读或最新的一篇

## 使用

开发调试：

1. 打开 CipherTalk 的「设置 → 插件」。
2. 开启「插件开发者模式」。
3. 选择「加载本地插件目录」，选中本目录。
4. 确认权限并启用「会话日记」。

安装打包：

```bash
node ../../plugin-sdk/cli.cjs pack .
```

然后在「设置 → 插件 → 安装插件」中选择生成的 `.ctp` 文件。

## 权限

- `sessions:read`：列出可选择的会话
- `messages:read`：读取所选会话指定日期的消息
- `stt:use`：转写语音消息
- `ai:use`：调用宿主已配置的大模型

插件没有申请网络权限；聊天内容不能由插件页面直接发送到外部网络。AI 与语音转写均经 CipherTalk 宿主能力调用，插件无法读取 API Key。

导出的备份文件位于插件私有存储之外，卸载插件不会删除它。备份包含日记正文、会话标识和生成时使用的提示词，请妥善保管。
